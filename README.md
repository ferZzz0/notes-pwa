# Заметки (PWA)

Приложение для заметок: устанавливается на телефон и компьютер как обычное
приложение (PWA) и работает офлайн. React 19 + TypeScript, собирает Vite,
офлайн-кэш и манифест делает vite-plugin-pwa (Workbox).

Адрес: https://notes-polik.sokolovpk.ru

Главный экран — раскрытая тетрадь из гладкой бумаги. Лист всегда на весь
экран (и под часами, и у выреза камеры) — за ним ничего не видно. Сначала лист
ровно по экрану: его нельзя сдвинуть или отдалить, только приблизить. Когда
ваш текст подходит к краю листа (ближе пятой части экрана), в эту сторону
открывается ещё целый экран бумаги — вниз, а у разворота и наружу (у одной
страницы край у корешка не растёт, верх листа тоже).

- одним пальцем — двигать лист (где он больше экрана или приближен), после
  броска он скользит по инерции;
- двумя пальцами — приближать и отдалять;
- двойное касание по бумаге — написать в этом месте (появится курсор);
  касание по тексту — править его; стёртый текст исчезает; пока открыта
  клавиатура, под листом есть место, чтобы поднять строку над ней;
- новая надпись и та, которой коснулись, выбраны: вокруг рамка с ручками
  (слева сверху — перенести, справа сверху — повернуть, справа снизу —
  размер), внизу панель — цвет чернил, шрифт (три рукописных и три
  печатных), удалить, готово. Пока не печатаете, надпись можно тащить и
  за сам текст. Касание по бумаге снимает выбор; следующая надпись
  начинается с тем же цветом и шрифтом;
- на компьютере: перетаскивание мышью, колесо — сдвиг, Ctrl/⌘ + колесо или
  щипок на тачпаде — масштаб.

Вертикально видна одна страница (её корешок — край экрана), горизонтально —
весь разворот; после поворота телефона лист всегда показан в полном
отдалении — с самого верха, как бы его ни приблизили до поворота.

Листов сколько угодно. Перелистывают светлыми кнопками-стрелками в нижних
углах экрана, на компьютере — ещё и стрелками ← → на клавиатуре: страница
загибается с нижнего уголка и уходит через корешок, под ней открывается
следующая, на загибе виден оборот; новая страница открывается с начала. На одной странице
к соседней странице того же разворота экран просто перелетает через корешок.
Вверху у корешка — номера страниц и дата, когда на развороте начали писать.

Шестерёнка внизу посередине — настройки. Пока там только отладка: когда
собрана версия (видно, дошло ли обновление) и «Стереть все данные» (с
подтверждением — это навсегда).

Записи и открытая страница хранятся в памяти телефона (у установленного на
iPhone приложения память своя, отдельная от Safari).

25.10.2026 вышло обновление, которое один раз стёрло все записи на каждом
устройстве (это были тестовые записи): при первом запуске новой версии
приложение стирает свою память и запоминает это, написанное после остаётся.
Чтобы стереть ещё раз, поменяй `RESET_ID` в `src/notes.ts` — отменить это
нельзя.

## Разработка

Нужен установленный Node.js.

```powershell
npm install        # один раз: ставит зависимости
npm run dev        # dev-сервер с мгновенной перезагрузкой (http://localhost:5173)
npm run check      # проверка типов TypeScript
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр production-сборки (http://localhost:4173)
npm run icons      # перегенерировать иконки из public/icon.svg
```

## Отладка

1. Запусти dev-сервер: `npm run dev` (оставь работать в терминале).
2. В VS Code нажми **F5** («Отладка (Chrome)») — откроется браузер с приложением.
   В списке конфигураций есть и вариант для Edge.
3. Точки останова ставь прямо в `src/**/*.tsx`.

Нюансы:

- В `npm run dev` service worker выключен, чтобы кэш не подсовывал старые
  файлы после правок. Офлайн-режим и плашку обновления проверяй через
  `npm run build` + `npm run preview` (http://localhost:4173).

## Как выкатить обновление

Версию кэша вручную поднимать не нужно: при каждой сборке service worker
получает новый список файлов с хэшами, и браузер сам замечает новую версию.
У пользователей появится плашка «Доступна новая версия» с кнопкой «Обновить».

Хостинг — Cloudflare (Workers Builds, как у zuma-pwa): каждый push в `main`
Cloudflare сам собирает и выкладывает на https://notes-polik.sokolovpk.ru
(конфиг — `wrangler.jsonc`).

### Если сайт открывается пустым

Российские провайдеры обрывают соединения с частью адресов Cloudflare
(`188.114.96.1`, `188.114.97.1`) примерно после 24 КБ: HTML успевает
загрузиться, а скрипт приложения — нет, страница остаётся пустой (в DevTools
скрипт висит в pending). Через `104.21.46.231` / `172.67.143.35` всё
работает. Какой адрес достанется, решает DNS, и это лотерея:

- обычный DNS провайдера и Яндекса отдаёт то рабочие, то «плохие» адреса;
- Google (`8.8.8.8`) и DNS-over-HTTPS Cloudflare («безопасный DNS» в
  браузере, «Частный DNS» на Android) — «плохие»;
- служебный адрес `notes-pwa.2004s-p.workers.dev` и предпросмотры веток
  (`*-notes-pwa.2004s-p.workers.dev`) — всегда «плохие», не открываются
  никогда, проверяй только свой домен.

Как проверить: DevTools → Network → первая строка → Headers →
Remote Address. Если там `188.114.x` — дело в этом.

Что помогает: выключить в браузере «Использовать безопасный DNS» и
перезапустить браузер; если всё равно пусто — открыть ещё раз позже.
Если приложение хоть раз загрузилось, дальше оно запускается из кэша,
а не скачавшееся обновление докачается при следующей попытке.
Со стороны Cloudflare на бесплатном тарифе это не исправить, надёжный выход —
хостинг вне Cloudflare. Пока решили остаться на Cloudflare.

## Файлы

- `src/main.tsx` — запуск React-приложения, подключение рукописных шрифтов
  (они собираются в приложение и работают офлайн)
- `src/App.tsx`, `src/App.css` — главный экран
- `src/components/Canvas.tsx` — полотно: перелёт, масштаб, инерция, двойное
  касание, границы листа (по экрану, растут вслед за текстом)
- `src/components/Paper.tsx` — бумага листа, линия корешка
- `src/components/Notebook.tsx` — тетрадь: развороты, тексты по двойному
  касанию, выбор надписи, одна страница или разворот, стрелки
- `src/components/PageTurn.tsx` — перелистывание: загиб страницы с уголка
- `src/components/TextBlock.tsx` — надпись в любом месте листа (цвет,
  шрифт, поворот, размер)
- `src/components/Selection.tsx` — рамка выбранной надписи с ручками
- `src/components/TextToolbar.tsx` — панель надписи: цвет, шрифт, удалить
- `src/components/Settings.tsx` — шестерёнка и настройки (отладка)
- `src/textStyle.ts` — чернила и шрифты надписей
- `src/orientation.ts` — вертикально ли держат телефон
- `src/notes.ts` — хранение записей, открытой страницы и последнего
  оформления в памяти телефона, разовая очистка всех записей (`resetOnce`)
  и «Стереть все данные» (`clearAll`)
- `src/index.css` — общие стили и цвета темы: бумага, чернила
  (светлая и тёмная)
- `src/components/UpdatePrompt.tsx` — регистрация service worker'а и плашки
  «готово к работе офлайн» / «доступна новая версия»
- `index.html` — точка входа Vite
- `public/icon.svg` — исходник иконки; PNG и `favicon.ico` рядом с ним
  генерирует `npm run icons` (настройки в `pwa-assets.config.ts`)
- `vite.config.ts` — конфиг сборки и PWA (манифест, офлайн-кэш)
- `wrangler.jsonc` — конфиг деплоя на Cloudflare
